# AI-Powered Cloud Compliance Automation

## 📌 Prerequisites
Before setting up the **AI-Powered Cloud Compliance Automation**, ensure you have the following:

- **Docker Installed**: [Install Docker From This Link](https://docs.docker.com/get-started/get-docker/)
- **OpenAI API Key**

## 🚀 Setup Guide
Follow these steps to set up and run the **AI-Powered Cloud Compliance Automation**:

### 1️⃣ Pull the Docker Image
  ```shell
  docker pull tariquesalat/ai-compliance-scanner:latest
  ```

### 2️⃣ Run the Docker Container
  ```shell
    docker run -d \
         --name ai-compliance-app \
         -e AWS_ACCESS_KEY_ID=${AWS_ACCESS_KEY_ID} \
         -e AWS_SECRET_ACCESS_KEY=${AWS_SECRET_ACCESS_KEY} \
         -e AWS_DEFAULT_REGION=${AWS_DEFAULT_REGION} \
         -e OPENAI_API_KEY=${OPENAI_API_KEY} \
         -p 8501:8501 \
         tariquesalat/ai-compliance-scanner:latest
  ```
Replace `${AWS_ACCESS_KEY_ID}`, `${AWS_SECRET_ACCESS_KEY}`, `${AWS_DEFAULT_REGION}` and `${OPENAI_API_KEY}` with valid credential values.

🔹 Tip: If you're using a .env file, export the key before running the container:
  ```shell
  export OPENAI_API_KEY=your_api_key
  export AWS_ACCESS_KEY_ID=your_aws_access_key
  export AWS_SECRET_ACCESS_KEY=your_aws_secret_key
  export AWS_DEFAULT_REGION=your_aws_region
    docker run -d \
         --name ai-compliance-app \
         -e AWS_ACCESS_KEY_ID=${AWS_ACCESS_KEY_ID} \
         -e AWS_SECRET_ACCESS_KEY=${AWS_SECRET_ACCESS_KEY} \
         -e AWS_DEFAULT_REGION=${AWS_DEFAULT_REGION} \
         -e OPENAI_API_KEY=${OPENAI_API_KEY} \
         -p 8501:8501 \
         tariquesalat/ai-compliance-scanner:latest
  ```

## 🌐 Accessing the Application
Once the application starts, open the appropriate URL in your browser:

- **For Localhost:**
  
  - Navigate to URL
    ```shell
    http://127.0.0.1:8501
    ```
- **For WSL (Windows Subsystem for Linux)**:
  - Get the WSL server's IP address
    ```shell
    ip addr show eth0 | grep "inet\b" | awk '{print $2}' | cut -d/ -f1
    ```
    If the output is `172.20.30.5`, update the browser URL to:
    ```shell
    http://172.20.30.5:8501
    ```

### 📄 Viewing Logs Inside the Container
If you want to view the logs generated by the application, you can access the container's shell and inspect the file.
#### 🔍 Step-by-Step to View Logs
1. Login to the Container Shell
  ```shell
    docker exec -it ai-compliance-app /bin/bash
  ```
This opens an interactive shell session inside the running container.

2.  Run below command to view the log file
  ```shell
    cat cis_api_scanner_logs.log
  ```
To view the live logs run 
  ```shell
    tail -f cis_api_scanner_logs.log
  ```
This will display live logs as and when the logs are updated

3. Exit the Container
  ```shell
    exit
  ```
### 🧹 Stopping and Removing the Container
When you're done using the AI-Powered Cloud Compliance Automation app, you can stop and remove the container to free up system resources.

#### ⛔ Stop the Running Container

To stop the container named `ai-compliance-app`, run:
  ```shell
    docker stop ai-compliance-app
    docker rm ai-compliance-app
  ```
🛑 Note: Removing the container deletes the instance, but not the image. You can re-run it anytime using the same image.

### 🔄 (Optional) Remove the Docker Image
If you want to remove the image as well (to reclaim disk space):
  ```shell
    docker rmi tariquesalat/ai-compliance-scanner:latest
  ```
